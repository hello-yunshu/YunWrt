# D9 · base 校验失败默认硬失败

- 状态：已采纳
- 日期：2026-11-12
- 关联：[迁移方案 §2.6、§6 D9](../plans/2026-11-11-yunwrt-migration.md)

## 背景

overlay 与 patch 是按上游具体文件内容写的。上游删路径、改结构、或新增同名文件时，覆盖会静默失效：镜像照常构建成功，问题到设备上才暴露。

## 决策

`verify-bases.sh` 对三类失效分别判定：

| 形态 | 判据 | 结果 |
|---|---|---|
| 覆盖目标消失 | `upstream_path` 不存在 | 硬失败 |
| 覆盖目标变形 | base `sha256` 不符 / 结构断言不匹配 | 硬失败 |
| 新增文件撞名 | `kind: add` 且上游已存在该路径 | 告警 + 标记 need-review，阻止发布 |

只有手动排障可加 `--allow-base-drift`；此时产物**不得发布**，并自动生成 need-review 记录。

## 后果

- 静默失效比构建失败代价高得多，因此默认选择让流水线红。
- 所有断言脚本在失败时必须非 0 退出，"打印警告后继续"不允许出现在验收路径上。
